## Design Context

### Users
Homelab enthusiasts and self-hosters who want the power of a reverse proxy without touching config files. They're typically comfortable with technology but not sysadmins — they want a GUI that makes complex networking tasks approachable. They configure things methodically but don't want to spend hours on it. They value "it just works" simplicity with the option to go deeper when needed.

### Brand Personality
**Synthwave pixel-portal.** The name "Waygates" evokes portals, networks, and transit — something decisive and a little electric. The UI is clean and modern; the pixel-art aesthetic lives exclusively in the logo wordmark (VT323 font). Everything else should feel sharp, spacious, and fast — not retro, not gamified.

### Aesthetic Direction
- **Identity**: Synthwave pixel-portal — precise and electric, not nostalgic or playful.
- **Anti-reference**: Raw terminal UIs, enterprise-gray dashboards, overly playful or gamified interfaces.
- **Visual tone**: Clean lines, generous spacing, clear hierarchy. The dark theme is the hero — true black canvas, near-black surfaces. Light theme is a neutral counterpart, both fully first-class.
- **Theme**: Light and dark mode, both first-class citizens.
- **Shape**: Square corners everywhere — `border-radius: 0`. No rounding on cards, inputs, badges, buttons, or dialogs.
- **Typography**:
  - **VT323** — logo wordmark only, never in the UI body.
  - **Space Grotesk** — all UI text: headings, labels, body copy, navigation.
  - **Space Mono** — data values, hostnames, code, monospaced technical content.

### Color Direction
Exact values from `ui/src/app.css`:

**Dark theme** (primary):
- Background: true black `#000000`; surfaces/cards: near-black `#0b0b12`
- Primary (periwinkle): `#6e72f0`; primary foreground: `#ffffff`
- Focus ring / accent: cyan `#34e1e0`
- Muted surfaces: `#15151f`; borders: `#22222f`

**Light theme**:
- Background: neutral off-white `#f7f7fa`; cards: `#ffffff`
- Primary (periwinkle): `#5862e0`; primary foreground: `#ffffff`
- Focus ring / accent: teal `#0e7b82`
- Muted surfaces: `#f1f2f6`; borders: `#e3e4ec`

**Both themes**:
- Destructive: red (`#d14a42` light / `#e5675f` dark)
- Standard semantic accents for warnings (amber) and healthy states (green) apply as needed; the identity accent is periwinkle + cyan/teal only.

### Design Principles
1. **Clarity over cleverness** — Every element should be immediately understandable. No jargon without explanation, no hidden functionality. If a homelab user can't figure it out in 5 seconds, simplify it.
2. **Power through simplicity** — Complex configurations should be broken into digestible steps. Progressive disclosure: show the basics first, reveal advanced options on demand.
3. **Sharp technical** — The interface should feel capable and precise without being cold or intimidating. Use clear language, helpful empty states, and encouraging feedback.
4. **Confidence through feedback** — Users managing proxies need to trust the tool. Show status clearly, confirm actions, provide undo where possible. Never leave the user wondering "did that work?"
5. **Consistent rhythm** — Maintain visual consistency across all pages. Same patterns for search, same patterns for data grids, same patterns for forms. Predictability builds confidence.
