# M3b — L4 (TCP/UDP) Proxy List Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the TCP/UDP (L4) proxy list to parity with the HTTP list (M2b): row selection + bulk enable/disable/delete, duplicate-a-proxy, and JSON export.

**Architecture:** Frontend-only, reusing M2b building blocks. Add TanStack row selection to the existing L4 list table; a contextual `ProxyBulkBar` (reused) drives client-side loops over the existing single-item endpoints. Because L4 exposes only a `PATCH /toggle` (no enable/disable), bulk enable/disable is a **smart toggle**: flip only rows whose `is_active` differs from the target. Duplicate seeds the M3a L4 create wizard from an existing proxy (clearing the unique `listen_port`). Export is a client-side JSON transform.

**Tech Stack:** React 19, TanStack Query/Table, rnui (`@e412/rnui-react`, Base UI — `render` not `asChild`), ky, Vitest.

## Global Constraints

- **No backend change.** Bulk ops are client-side `Promise.allSettled` loops over existing endpoints (`PATCH /l4-proxies/{id}/toggle`, `DELETE /l4-proxies/{id}`, `POST /l4-proxies`). No L4 enable/disable/bulk/import endpoints are added.
- **Bulk enable/disable = smart toggle.** L4 has only toggle. Each list row carries `is_active`. To set a target state, toggle ONLY the selected rows whose `is_active !== target`. Rows already at the target are left untouched (idempotent).
- **Duplicate clears `listen_port`** (composite unique key is `(listen_port, protocol)`; clearing the port forces the user to pick a free one — the field shows "Port is required") and suffixes the name with " (copy)". The M3a `L4ProxyForm` already seeds from `initialData` whenever present.
- **No ACL column** (L4 has no ACL concept). **Import is out of scope** (a later milestone, as HTTP import was).
- **Reuse, don't fork:** `ProxyBulkBar` (`@/components/proxy/proxy-bulk-bar` — generic: `count`/`onEnable`/`onDisable`/`onDelete`/`onClear`/`running`); `downloadJson` + `summarizeBulkResults` (`@/lib/proxy-export`); the checkbox-column pattern from `proxy-data-grid.tsx` (rnui `Checkbox` with `indeterminate={getIsSomePageRowsSelected() && !getIsAllPageRowsSelected()}`, `getRowId`, `enableRowSelection`).
- **rnui:** compose via `render`, never `asChild`. Selection keyed by `getRowId: (row) => String(row.id)`.
- **No `tsc` gate.** Gate each task on `pnpm --dir ui build` + `pnpm --dir ui check` + `pnpm --dir ui test run`. Run from repo root `/home/aloks98/projects/waygates`.
- The L4 list query key is `['l4-proxies']`; the L4 hook is `ui/src/hooks/use-l4-proxies.ts` (`create`/`update`/`remove`/`toggleActive`).

```ts
import type { CreateL4ProxyRequest, L4Proxy } from '@/types/l4-proxy';

export type L4Export = CreateL4ProxyRequest;

export function toL4ExportPayload(proxies: L4Proxy[]): L4Export[] {
  return proxies.map((p) => ({
    name: p.name,
    description: p.description,
    listen_port: p.listen_port,
    protocol: p.protocol,
    is_active: p.is_active,
    routes: (p.routes ?? []).map((r) => ({
      priority: r.priority,
      matcher_type: r.matcher_type,
      sni_hostnames: r.sni_hostnames,
      allowed_ip_ranges: r.allowed_ip_ranges,
      regex_pattern: r.regex_pattern,
      upstreams: r.upstreams.map((u) => ({ host: u.host, port: u.port, weight: u.weight })),
      load_balancing_policy: r.load_balancing_policy,
      tls_terminate: r.tls_terminate,
      tls_passthrough: r.tls_passthrough,
      proxy_protocol_version: r.proxy_protocol_version,
    })),
  }));
}

export function idsToToggle(proxies: L4Proxy[], ids: number[], enable: boolean): number[] {
  const byId = new Map(proxies.map((p) => [p.id, p]));
  return ids.filter((id) => {
    const p = byId.get(id);
    return p !== undefined && p.is_active !== enable;
  });
}
```

Adjust the route field names to match `types/l4-proxy.ts` `CreateL4RouteRequest` exactly (read it). If `CreateL4ProxyRequest` doesn't structurally accept this object, define a local `L4Export` interface mirroring the create shape instead of aliasing it.

```ts
const [isBulkRunning, setIsBulkRunning] = useState(false);

const bulkToggle = async (ids: number[]) => {
  setIsBulkRunning(true);
  try {
    const results = await Promise.allSettled(ids.map((id) => api.patch(`l4-proxies/${id}/toggle`)));
    await queryClient.invalidateQueries({ queryKey: QUERY_KEY });
    return summarizeBulkResults(results);
  } finally {
    setIsBulkRunning(false);
  }
};

const bulkRemove = async (ids: number[]) => {
  setIsBulkRunning(true);
  try {
    const results = await Promise.allSettled(ids.map((id) => api.delete(`l4-proxies/${id}`)));
    await queryClient.invalidateQueries({ queryKey: QUERY_KEY });
    return summarizeBulkResults(results);
  } finally {
    setIsBulkRunning(false);
  }
};
```

Return `bulkToggle`, `bulkRemove`, `isBulkRunning` from the hook. (Verify the ky verb for toggle is `patch` — match the existing `toggleActive` mutation's call.)
